我曾仔细的比较了各个发行版, 由于当时的浅薄, 我曾因 Fedora 默认带着的 Gnome 环境拒绝此发行版, Ubuntu 在搭建集群时候的表现让我对其并没有好感. Arch 对我当时又太难 -- 虽然后面证明这只不过是想象中的困难. NixOS 是一个理念相当先进的发行版, 最明显的缺点就是配置方式对新手的要求太高了. Gentoo 可以从源码层面对软件进行自定义设置, "万物皆可编译", 听说性能很不错, 但和NixOS 一样, 上手难度极高. 

Debian 有着很多被人诟病的缺点, 软件包分散, Stable 版本软件老旧, Testing 一旦在新版本发布前夕非常容易炸.

从感性的角度来说, 它是在我看来唯一一个将自由浪漫和现实实际结合在一起的发行版, 它既满足了自由软件之要求, 也解决了实际生活中的需要, 它既有老派极客所拥有的严谨, 同时也对事物有着惊人的接纳的能力. 它不像 Guix 那么极端, 也不像 MacOS 那样封闭, 当然, 它也比 Windows 稳定. 它对所有事物都有着惊人的宽容.   - 我们可以安装大量的不自由甚至是闭源的软件包. - 即使是它的名字, Debian, 也充满着浪漫的色彩. Debian, 嘴唇开河, 舌尖顶着上颚, 猛然爆发, 吐气开声,  一对恋人的名字即被在世间记录了下来.  

每一个使用它的人都不得不承认, 它的稳定性无可挑剔, 极其可靠, 稳如磐石. 而代价即是远远"落后"两三年的老旧软件包, 因此饱受争议, 这是悲哀, 是无奈, 也是稳定所需要的代价. 它的每一个软件包都经过了大量的测试, 直到稳定可靠. 它也因为修改软件包以符合自己的发行哲学而被人吐槽, 认为自作聪明, " 难用" , 但我们必须得承认, 这是在集众人之力建造一个自己的精神家园, 在这里, 我们不用担心软件公司的一个决定而让众人努力付诸东流, 同时, 我们也不反对专业软件在此扎根发芽. 这是我们共同的精神家园.

对于厌倦了某些发行版自作主张的添加一些我们不需要, 不喜欢, 甚至不认可的东西来说, Debian 是一个折衷的选择. 我们可以以相对原生的方式来配置和使用它. 我知道Gentoo 更加符合原生的选择, 但正如我所说, 它上手难度极高, 并不时候新手用户.

曾经有人戏称 Debian 是养老发行版, 它确实是相对省心的选择. 对于追求实用而却又有一点自由软件浪漫追求的人来说, 它是一个合适的选择. 它不用像 Gentoo 那样有着深厚的知识, 不想 NixOS 那样繁琐, 也不像 Ubuntu 和 Fedora 那样将生命周期完全系于公司之手, 也不像一些小众发行版完全有几个人来支撑. 它保证了生命周期, 社区活力, 软件数量, 以实用的角度来说, 几乎是完美.
